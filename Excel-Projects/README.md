# Consumer Complaints Analysis (Excel)

## Project Overview
This project focuses on analyzing customer complaint data from the banking sector to understand customer satisfaction and service issues.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts and Visualizations

## Key Analysis
- Analyzed customer complaints across multiple banking institutions
- Identified trends in customer satisfaction and complaint categories
- Compared performance of banks using ratings and complaint volume
- Created summary reports and charts for clear insights

## Outcome
The analysis helped identify key problem areas and provided actionable insights to improve customer experience and service quality.
